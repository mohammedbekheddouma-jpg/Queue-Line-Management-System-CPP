# Queue Line Management System (C++)

A Queue Line Management System developed in **C++** using **Object-Oriented Programming (OOP)**. This project simulates a real-world ticket-based queue management system with automatic ticket generation, waiting time estimation, and client serving operations.

## Features

- 🎫 Automatic ticket generation
- 📋 Queue information display
- ⏳ Waiting time estimation
- 👥 Client serving simulation
- 🔄 Support for multiple queues
- 📅 Custom Date & Time utilities
- 💻 Cross-platform compatibility (Linux with g++)

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)
- g++

```bash
g++ -std=c++17 main.cpp -o QueueLine
```

## How to Run

```bash
./QueueLine
```
